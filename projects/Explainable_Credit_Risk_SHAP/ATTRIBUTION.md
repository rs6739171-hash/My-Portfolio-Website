# Attribution and provenance

This project was independently implemented for Rishabh Shukla after reviewing the public repository:

- Architecture reference: `tanishq-latent/Credit-Risk-Assesment-using-SHAP`
- Original URL: https://github.com/tanishq-latent/Credit-Risk-Assesment-using-SHAP

At the time of review, the reference repository did not expose a README or visible license file. Therefore its notebook source, CSV dataset, pickled model, threshold artifact, frontend code and other implementation files were not copied into this project.

This implementation uses newly written code, generated synthetic data, a newly trained model, SHAP-based field explanations, scenario analysis, tests, evaluation, documentation and deployment configuration.
